# Changelog

All notable changes to Tricore are listed here. Each release is published for OJS 3.3, 3.4 and 3.5 (tags `v<version>-ojs3.3`, `v<version>-ojs3.4`, `v<version>-ojs3.5`).

## 1.0.0 (2026-09-26)

First public release.

- Colour pickers for the primary, secondary, accent, header and footer colours, with automatic black or white text.
- Typography choices using fonts served by OJS itself.
- Layout options: header layout, page width and corner rounding.
- Journal homepage blocks: hero with two buttons, journal metrics, journal summary, latest articles, current issue and indexing information (multilingual).
- Sidebar setting per page type (homepage, archive, issue, article, About, static pages, search, announcements). Login and registration pages never show the sidebar.
- Views and downloads on article lists, the archive and the article page, with an option to hide them.
- Archive as a grid of issue covers.
- Site landing page: journal cards with covers and ISSN, article search across journals, statistics and a sign-up call to action.
- Redesigned login, registration, lost password and password reset pages.
- Social media links in the footer.
- Accessibility: visible focus, `aria-expanded` menus, reduced motion, right-to-left support and a print stylesheet.
- English and Indonesian translations.
